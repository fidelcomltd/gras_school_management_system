# Golden Royal Ark School — website

The public site for [goldenroyalark.com](https://goldenroyalark.com): Home, About and Contact, with a
contact form that emails the school and links to the parents' result portal.

```bash
cp .env.example .env.local   # then fill in what you need (all optional locally)
npm install
npm run dev                  # http://localhost:3000
```

Everything else (structure, rules, environment, Netlify + Resend setup, SEO) is in [AGENTS.md](AGENTS.md).
