- 2026-09-04 **`ci.ps1` runs `Format` before `Build`, and on this machine that makes the common case
  slower — the card's own cheapest-first premise is contradicted by the order it specifies.**
  TASK-0016's acceptance criterion fixes the order as restore → format → build, so that is what was
  implemented. Measured by backend-dev with `Measure-Command` against the exact commands the gates
  run: `dotnet format --verify-no-changes --no-restore` takes **30.5s and 31.1s** across two runs,

  format gate gets slower, or fold it into the build via an analyzer so it costs nothing extra.
  Owning card: TASK-0016 (closed) — reopen or raise a successor if the numbers change.

  header** — §6 requires "Mutating endpoints that can be retried accept an `Idempotency-Key`", and
