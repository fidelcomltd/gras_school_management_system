## The finding

```
Project `SchoolManagement.IntegrationTests` has the following vulnerable packages
   > SSH.NET   2025.1.0   High   https://github.com/advisories/GHSA-q939-rpr3-3284
```

Verified by the orchestrator on 2026-08-26:

- **Confined to `SchoolManagement.IntegrationTests`.** Every other project — Api, Application,
  Domain, Infrastructure, ArchitectureTests, UnitTests — reports no vulnerable packages. It is a
  test-only dependency and **never ships to production**.
- Reached transitively: `Testcontainers.PostgreSql 4.13.0` → `Docker.DotNet` → `SSH.NET`.
- The vulnerable surface is Docker.DotNet's SSH transport for **remote** Docker hosts. This
  project's fixture only ever talks to a local daemon or an externally supplied
  `POSTGRES_TEST_CONNECTION`, so the path is not one we exercise.
- **Pre-existing, not introduced by TASK-0002** — confirmed: no `.csproj` or
  `Directory.Packages.props` change in that card, package graph unchanged.
- `Testcontainers.PostgreSql 4.14.0` exists. It has not been tried.

Background written up by the implementing agent in `backend/docs/ASSUMPTIONS.md` §3.8, which
deliberately stopped short of accepting the risk unilaterally. That was the right call.
