## Goal

The non-academic half of a result sheet becomes configurable data: rating scales as records, the
school's own trait lists, and the nursery development domains with their indicators. Phase 3's
non-academic input card cannot start without this.

## The trap, same shape as TASK-0069's

§6.2.7 specified **one school-wide trait scale** and seeded trait lists that were guesses made
before the school's forms arrived. §6.2.13 replaces all of it:

| §6.2.7 says | Build this instead |
|---|---|
| `trait_scale`, one, school-wide | `rating_scale` + `rating_scale_point`. **Each rating block references a scale by id** — conflict item 6. The two sheets genuinely use different scales |
| Guessed affective/psychomotor lists | The school's own **11 affective and 8 psychomotor** traits from Appendix F.3 |

## Acceptance criteria

- [ ] `rating_scale` and `rating_scale_point` persist. `point_label` is 120 chars so a descriptive
      legend fits; `point_code` is 1 char holding E, S, I or N as printed in the column heading.
- [ ] Three seeded scales: Nursery development (E/S/I/N), Primary trait (E/I/N), Five-point numeric
      (5-1, legend from Appendix A entry 48, referenced by nothing, retained as an alternative).
- [ ] `development_domain` and `development_indicator` persist with the fields §6.2.13 lists,
      including `rating_scale_id` and `allows_indicator_comment` **per domain**, so a fifth domain
      on a three-point scale needs no code change.
- [ ] Seeds load 4 domains and 45 indicators from Appendix E.3, and the 11 + 8 traits from F.3.
- [ ] Adding an indicator mid-term is allowed and takes effect immediately on the entry screen.
- [ ] Removing an indicator that has ever been rated is **refused in favour of archiving**, with
      §6.2.13's exact message. Archived items stay on historical sheets via the snapshot and
      disappear from new entry screens.
- [ ] Domains and indicators are **section-scoped**. The seed leaves primary with the affective and
      psychomotor blocks only; nothing in code may prevent a school configuring domains for primary.
- [ ] A rating is a choice from the scale's fixed point set, never a free value — this is one of
      the invariants §25's closing note fixes in code deliberately.
- [ ] The >60-indicator warning exists on the entry surface contract (the count, not the UI copy).
- [ ] Versioned into `config_version` like every other settings group.
- [ ] Contract delta approved before implementation (done 2026-09-18); drift gate green.
- [x] Carried from TASK-0070 closure: `CreateSubjectHandler` `code_duplicate` unit test added.
- [ ] Gates green via `-IntegrationFilter` scoped to your classes. Never the full gate.
