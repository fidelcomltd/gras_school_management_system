# Task cards

One file per card, named `TASK-####.md`, following the §4.2 template in the root
[CLAUDE.md](../../CLAUDE.md). Numbering starts at `TASK-0001` and never reuses a number.

Empty until product scope is confirmed — see Open question 7 in [STATE.md](../STATE.md).
Cards describe what a user can do, so they cannot be written before the domain is known.
