## Goal

An administrator can open the rooms for a session — one at a time mid-term, or all of them at once
when a session opens — see how full each is, and assign form teachers.

## Scope (`features/arms/`)

- List (`GET /arms`, cursor-paginated), filtered by session, level, status, form teacher, with
  free-text search matching the composed display name (typing `2c` finds Primary 2C).
- Create one (`POST /arms`, `Idempotency-Key` REQUIRED), with the label pre-filled from
  `GET /arms/next-label` and editable.
- Bulk create (`POST /arms/bulk`, `Idempotency-Key` REQUIRED) — **`dryRun` first, always**. Show
  the preview listing every arm that will be created with its composed display name, and only
  commit on explicit confirmation.
- Detail (`GET /arms/{id}`), edit (`PATCH /arms/{id}`), delete (`DELETE /arms/{id}`).

- The arm list carries `formTeacherAdminId` (an opaque id), **not** the teacher's name. Spec 6.4.5

  client-side from the admins the caller can already read if that is cheap; if it is not, render
  the gap honestly and say so in your report — **do not render a bare GUID to a user**.
