# TASK-0009 — Move the document-property contract tests off the database

Owner: backend-dev
Depends on: TASK-0002 (closed)
Contract impact: none
Status: done

## Goal

`OpenApiContractTests` asserts properties of the **generated OpenAPI document**. Not one of its
tests touches the database or a request handler — they reach the document incidentally, through a
live `WebApplicationFactory` HTTP call, which is what couples them to `SchoolManagement.IntegrationTests`
and therefore to database availability.

That coupling is not theoretical. On 2026-08-26 `EverySchema_HasAnExample` would have caught
TASK-0002's missing `SecureArmResponse` example immediately. It did not, because no database was
reachable in the implementing session, so it skipped silently while everything around it went
green — and the gap reached the committed contract. It was eventually caught only because the
orchestrator obtained a database and re-ran, and independently because a frontend agent noticed the
derived mock returning an empty body.

A check that disappears exactly when the environment is degraded is worse than no check, because
its silence reads as success. Move these so they run everywhere, always.

## The tests in question

Identified by the implementing agent during the TASK-0002 reopen — all eight assert document
properties and need no database:

- `EverySchema_HasAnExample`
- `EverySchema_HasADescription`
- `EveryOperation_HasASummaryDescriptionAndOperationId`
- `EveryOperation_DocumentsItsErrorResponses`
- `Document_HasApiLevelDocumentation`
- `EveryDateTimeProperty_HasAnExample`
- `Document_DescribesTheReferenceEndpoints`
- `Document_UsesConcreteVersionSegmentsNotRouteTemplates`

None. This card moves tests; it does not change the API.

## Acceptance criteria

- [ ] The eight tests above run without a database and without `WebApplicationFactory`, reading
      the build-generated document directly — the same source `ci.ps1`'s drift gate already
      regenerates without a database.
- [ ] They live where they will always run. `SchoolManagement.ArchitectureTests` is the natural
      home; if you judge a separate `ContractTests` project better, say why in the log first.
- [ ] **Prove the gap is closed:** with `POSTGRES_TEST_CONNECTION` unset and no container runtime,
      run the suite and show these eight tests EXECUTING rather than skipping. Paste it. This is
      the single acceptance criterion that matters — everything else is mechanics.
- [ ] **Prove they still catch the original defect:** temporarily remove the `SecureArmResponse`
      example, confirm `EverySchema_HasAnExample` fails, restore it. Paste both states. A relocated
      test that no longer detects what it was written for is worse than the one being replaced.
- [ ] Nothing genuinely requiring a database is moved out of `IntegrationTests` alongside them.
      Check each one; do not move by file.
- [ ] Skip counts stay honest: the `.github/workflows/backend-ci.yml` guard that derives skips as
      `total - passed - failed` still behaves, and the totals it checks reflect the new split.
- [ ] `./backend/scripts/ci.ps1` green apart from the known vulnerable-dependency gate
      (TASK-0007). Paste the output.

`backend/scripts/generate-openapi.ps1` already produces the document with no database, so the
mechanism you need exists — reuse it rather than inventing a second path to the same artefact. Two

keeps closing.

Keep this card mechanical. Its value is entirely in the two "prove it" criteria above.
