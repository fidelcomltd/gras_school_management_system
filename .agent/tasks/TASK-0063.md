## Goal

A Super Admin corrects a wrongly-issued registration number — usually a wrong admission year — by
typing the new number in full. The old number survives permanently as a lookup alias, so a parent
holding a pin slip printed with the old number still reaches the right child.

## Contract delta

- `POST /pupils/{id}/registration-number` — body `registrationNumber` (the new number, typed in
  full) and `reason` (**minimum 10 characters**). Privilege `pupil.regnumber.correct`, Super Admin
  only. 409 where the new number collides.

## Acceptance criteria

- [ ] **The system does not generate the new number** (6.5.10) — the administrator types it. A
      handler that composes one from settings fails this card.
- [ ] The new number must be unique against BOTH `pupil.registration_number` AND
      `pupil_reg_number_history`. Two tests, one per table — a check against only the live table is
      the obvious bug here.
- [ ] The old number is written to `pupil_reg_number_history` with reason, actor and timestamp, and
      is never deleted. A test corrects twice and asserts BOTH old numbers remain as aliases.
- [ ] `reason` under 10 characters is rejected.
- [ ] The counter is NOT touched — a correction consumes no serial. Asserted against the counter row.
- [ ] **Published result snapshots are not rewritten** (6.5.10). Assert the snapshot still holds the
      number as printed. If result snapshots do not exist yet, say so in the closing note rather
      than inventing one — the orchestrator files the drift entry.
- [ ] Audited: the correction writes an audit event carrying old number, new number and reason.

## Out of scope

- **The portal redirect notice** — verbatim `This pupil's registration number is now
  GRAS/2026/0041. Use that number in future.` The portal lookup does not exist. This card builds
  the alias row it will read; the portal card renders the sentence. Flag it in your closing note.
- Pins. 6.8.2 says pins reference no pupil and no number, so nothing about them changes here.
- Any bulk or self-service correction path. Super Admin, one pupil, one reason.
