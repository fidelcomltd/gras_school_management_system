## Approved decisions, binding (full text in the archive entry)

- Format `^[\x21-\x7E]{1,255}$`; fingerprint is method + path + **caller** + normalized body hash.
- `400 idempotency.key_missing` · `400 idempotency.key_malformed` ·
  `409 idempotency.key_conflict` (same key, different fingerprint) ·
  `409 idempotency.request_in_progress` (concurrent, retriable).
- Genuine replay returns the original status and body, plus a response header
  `Idempotency-Replay: true`.
- **Retention 24 hours**, scheduled purge, one `audit_event` per purge run
  (`actor_admin_id: null`, `action: system.idempotency_purge`). §9.9.
- **Stored responses are redacted before storage** of any one-time credential. See the
  `temporaryPassword` ruling in the archive entry — the redaction hook is built here, its first
  caller is TASK-0027.

## Acceptance criteria

- [ ] Applied once in the API layer as a filter/extension (mirroring `RequireCsrfToken()`), never
      per-endpoint.
- [ ] **Request fingerprinting**: a reused key with a different payload is rejected, not replayed
      against an unrelated response.
- [ ] **Caller isolation**: the same key from a different caller is a different request, with a
      test.
- [ ] **Stored-response replay**: a genuine repeat returns the original response and the
      `Idempotency-Replay: true` header, and performs the side effect exactly once — proven by a
      test that counts rows, not by asserting the response alone.
- [ ] **Concurrent duplicates**: two in-flight requests with one key produce one side effect and
      one `409 idempotency.request_in_progress`, proven under real concurrency, not sequenced calls.
- [ ] **Redaction hook** exists and is proven: a response field marked one-time is absent from the
      stored copy, asserted by reading the row back.
- [ ] **Retention purge implemented and proven** — a row past the window is gone after a purge run,
      and the purge writes its audit event. An indefinite table is a defect, not a deferral (§9.9).
- [ ] `generate-openapi.ps1` produces no diff; `contracts/openapi.json` and `CONTRACT.lock`
      unchanged, and you say so explicitly.
- [ ] `./backend/scripts/ci.ps1` green with the integration suite RUNNING (`Skipped: 0`).
