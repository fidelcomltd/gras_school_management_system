## Acceptance criteria

- [x] **The READMEs must stop prescribing a bypass of the generated client.**
      `src/features/README.md:56-62` currently says feature hooks call the `@/lib/http` verb helpers
      "and nothing else", and its worked example does `getRequest<IStudentListItem[]>('/api/v1/Students')`
      — a hand-written response type and a hardcoded path. `src/api/README.md:74-75` sanctions the
      same "for anything not yet worth a typed wrapper". §7 says all server communication goes
      through the generated client; §3 says the frontend never guesses a response shape. Rewrite both
      so the typed `apiGet`/`apiPost` path is the ONLY documented route, and rewrite the worked
      example to use it with a contract-derived type. If a verb-helper escape hatch is genuinely
      needed for something, say precisely what and why — do not leave a general permission.
      **This is the most important item in the card**: it is the template the first feature agent
      copies, and it is why it is carded rather than left as a nice-to-have.
- [x] **`npm run lint` must be able to fail on warnings.** `package.json:14` is bare `oxlint`, which
      exits 0 with warnings present. Add `--max-warnings=0`. This makes the whole `suspicious`
      category plus `no-console`, `react/no-array-index-key`, `react/only-export-components`,
      `typescript/consistent-type-imports` and `jsx-a11y/no-autofocus` actually enforceable, and makes
      `CONVENTIONS.md:290` ("currently zero warnings; keep it that way") true rather than aspirational.
      Run it and confirm the tree is still clean — the audit measured zero diagnostics of any
      severity, so this should not surface work. If it does, report rather than mass-fix.
- [x] **Stop re-exporting the raw axios instance.** `src/lib/http/index.ts:1` exports `httpClient`.
      Nothing — lint, typecheck, or `src/test/http-boundary.test.ts`, which matches `from 'axios'`
      and `fetch(` — prevents a feature importing it and issuing a request that skips `ApiError`
      normalisation and 401 handling. It is unused outside `src/lib/http/`, so removing the export
      costs nothing. Extend `http-boundary.test.ts` to also fail on a `httpClient` import from
      outside `src/lib/http/`, so the rule is enforced rather than merely tidied.
- [x] **Wrap the catch-all route in an `ErrorBoundary`.** `src/app/router/app-router.tsx:25-37`.
      The file's own doc comment at line 8 claims "Each route wraps its element in an
      `ErrorBoundary`", which is false as written — fix the code, and leave the comment true.
- [x] `npm run verify` and `npm run check:api-drift` both green. Paste the output.
- [x] `HANDOFF.md:19` says 120 tests; it is 124. Correct it while you are there.
