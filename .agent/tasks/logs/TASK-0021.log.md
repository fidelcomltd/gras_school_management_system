  pattern. New feature: `src/features/auth/` (sign-in screen + form, landing screen, `api.ts`
  hooks, `types.ts`, zod schema) — none of the hooks call `setSession` themselves, the http-client
  interceptor arms it centrally from any of the four `AuthSessionResponse`-shaped endpoints.
