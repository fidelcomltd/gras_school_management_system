# TASK-0029 — Regenerate the client and complete the typed wrapper surface

Contract impact: none — this card CONSUMES the contract, it never moves it

## Goal

`src/api/schema.d.ts` matches the committed contract again, and the typed client can actually
express the operation shapes that contract now contains. Today it cannot: `client.ts` exposes only
`apiGet` and `apiPost`, and neither threads a path parameter. TASK-0027 shipped five `/admins*`
paths that need `PATCH`, `DELETE` and `{id}` templating, so the first caller to try would have to
reach around the typed layer — which §4.4 check 3 makes a blocker.

## Contract delta

None. `contracts/openapi.json` is regenerated by the BACKEND only (`generate-openapi.ps1
-Promote`). If regeneration here produces a diff in the document, stop — that is drift, not a task.

## Acceptance criteria

- [x] `npm run generate:api` re-run; `src/api/schema.d.ts` matches the committed contract, generated
      header intact, and NOT hand-edited in any way.
- [x] `npm run check:api-drift` clean (§4.4 check 2 — the gate that is red today).
- [x] `apiPatch` and `apiDelete` added to `client.ts`, typed the same way `apiGet`/`apiPost` are
      (`PathsWithMethod<'patch'>` / `<'delete'>`). The transport already exists — `patchRequest` and
      `deleteRequest` are in `src/lib/http/request.ts`; only the typed wrapper is missing.
- [x] **Path templating.** `apiGet`'s signature threads query params through `RequestOptions.params`
      and has no path-parameter support at all. Every `/admins/{id}` operation needs it, and it must
      be TYPE-DRIVEN from `operations[...]["parameters"]["path"]`, not a string the caller formats.
      A caller omitting a required path param must fail typecheck.
- [x] `Idempotency-Key` is expressible on the operations that declare it — REQUIRED on
      `POST /admins`, accepted on `PATCH /admins/{id}`, `POST /admins/{id}/status` and
      `POST /admins/{id}/password-reset`. Required means the type system says so, not a comment.
- [x] No raw `fetch(`/`axios` against the API host outside `src/api/` (§4.4 check 3).
- [x] `npm run verify` green (typecheck, lint, test, build) plus `npm run test:e2e`, `Skipped: 0`.
