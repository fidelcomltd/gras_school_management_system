## Goal

A class teacher opens one sheet per arm, subject and term, types CA and examination marks (or ticks
absent), and saves the whole sheet at once. A Super Admin can void a subject's marks with a reason.
The first save creates the arm's result set in Draft. This is the storage the computation engine
(TASK-0071) reads. Nothing is computed here.

## Contract delta (approved; full text in the deltas archive)

**Route shape departs from §6.7.13's `?arm_id=` query form, on purpose.** `PrivilegeAuthorizationHandler`
resolves scope from `RouteValues` only (`Api/Security/PrivilegeAuthorizationHandler.cs:91`), so an
arm-scoped grant cannot be checked against a query parameter. Precedent: `GET /arms/{id}/subjects`.

| Op | Path | Privilege / scope | Success | Errors |
|---|---|---|---|---|
| GetScoreSheet | `GET /api/v1/arms/{armId}/score-sheets?subjectId=&termId=` | `result.view`, Arm | 200 `ScoreSheetDto` | 404 arm/subject/term; 422 `subject_not_in_effect` |
| SaveScoreSheet | `PUT /api/v1/arms/{armId}/score-sheets` | `result.score.enter`, Arm | 200 `ScoreSheetDto` (refreshed) | 422 per-cell list; 409 `result_set_locked`, `term_closed`, `session_closed`, `score_sheet_stale` |
| VoidScoreSheet | `POST /api/v1/arms/{armId}/score-sheets/void` | `result.score.void`, Arm | 200 `{ voidedCount }` | 422 reason; 409 `result_set_locked` |

- `ScoreSheetDto`: `armId, subjectId, termId, version` (string, null before any row exists),
  `resultSet` (`{ id, state, needsRecompute }` or null), `components[]` (non-examination only,
  settings order: `id, label, maxMark`), `examination { id, label, maxMark }`, `rows[]`
  (surname then id: `pupilId, registrationNumber, displayName, componentMarks` map id→int|null,
  `examMark` int|null, `examAbsent`, `caTotal` int|null, `subjectTotal` int|null — the two totals
  null unless the row is complete).
- `SaveScoreSheetRequest`: `subjectId, termId, version` (nullable), `rows[]` of `pupilId,
  componentMarks, examMark, examAbsent`. **Every non-examination component id must be a key** in
  `componentMarks`; a missing key is 422 `component_missing` (§6.7.3). **A null value is a blank
  cell, never zero.** Per-cell 422 codes: `score_out_of_range` (message names the maximum, e.g.
  "Maximum for CA1 is 20"), `score_exam_conflict` (absent AND a mark), `component_unknown`,
  `pupil_not_in_arm`. Any failing cell rejects the whole save.
- `VoidScoreSheetRequest`: `subjectId, termId, reason` (required, 10–500 chars, matches §6.7.11's reason rule).
- `Idempotency-Key` **accepted, not required** on PUT and void (standing obligation). A retried PUT
  otherwise 409s on its own stale `version`. Copy `AdminAccountEndpoints.cs:73`.
