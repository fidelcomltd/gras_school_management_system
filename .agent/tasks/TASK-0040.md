## Acceptance criteria

- [ ] `npm run generate:api` re-run against the committed contract; `src/api/schema.d.ts` rewritten
      by the generator, never by hand. Report `git diff --stat`.
- [ ] `npm run check:api-drift` → "No drift."
- [ ] All nine operations proven reachable through the existing generic wrapper. **Expect to write
      ZERO new lines in `client.ts`/`client-types.ts`** — every one is GET/POST/PATCH/DELETE and
      all four methods are already generic. If you find yourself adding wrapper code, say why in
      your report; TASK-0033 and TASK-0037 both established that a new operation on an
      already-supported method needs no hand-written code.
- [ ] **Both negative typing directions proven, not one** (this is what TASK-0037's first dispatch
      missed): a `@ts-expect-error` case for an OMITTED required `Idempotency-Key` on
      `CreateSection` and `CreateLevel`, **and** a `@ts-expect-error` case for an
      `idempotencyKey` passed to an operation that declares none — `ListSections` (options type
      carries nothing beyond `signal`/`timeout`) and `ListLevels` (options type is not trivially
      empty, so the rejection is not just "an empty type rejects everything").
- [ ] Each `PATCH`/`DELETE`/`GET`-by-id operation proven to reject an omitted required path
      parameter.
- [ ] **§8 enum tolerance proven for the new `LevelStatus` enum** via a `server.use(...)` MSW
      override returning an unrecognised member, asserting it passes through unchanged rather than
      throwing. **Write the override route as `:id`, not `{id}`** — MSW does not treat the
      contract's `{id}` template as a parameter, and `openapi-handlers.ts`'s `toMswRoute` helper
      exists for exactly this; an override bypasses that helper and needs the conversion by hand.
      TASK-0037 lost a run to this.
- [ ] `npm run verify` green (typecheck, lint, test, build) with counts pasted, `Skipped: 0`.
- [ ] `npm run test:e2e` — re-run only if anything e2e-relevant changed; say explicitly which and
      why if you skip it.
